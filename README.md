## 1. 理论计算（卷积层输出尺寸与参数量）

**题目**：一个 227×227×3 的输入图像，经过一个使用 96 个尺寸为 11×11×3、步长为 4、填充为 0 的卷积核的卷积层，其输出特征图的尺寸（宽、高、深度）是多少？该层总共有多少个需要学习的参数（不考虑偏置）？

### 1.1 输出特征图尺寸

卷积输出尺寸（宽和高方向）的通用公式：

```
输出尺寸 = ⌊(输入尺寸 + 2×填充 − 卷积核尺寸) / 步长⌋ + 1
```

代入宽、高方向的数据（输入 227，填充 0，卷积核 11，步长 4）：

```
⌊(227 + 2×0 − 11) / 4⌋ + 1 = ⌊216 / 4⌋ + 1 = 54 + 1 = 55
```

- **宽 = 55，高 = 55**
- **深度 = 卷积核个数 = 96**（每个卷积核产生一张输出特征图，堆叠为输出通道）

> 这正是经典网络 **AlexNet 的第一层**：输入 227×227×3 的图像，96 个 11×11×3 卷积核、步长 4，输出 55×55×96。

**答案：输出特征图尺寸为 55 × 55 × 96。**

### 1.2 参数量

不考虑偏置时，每个卷积核需要学习的参数 = 卷积核自身的权重数：

```
每个卷积核参数 = 11 × 11 × 3 = 363
```

共 96 个卷积核：

```
总参数量 = 96 × 11 × 11 × 3 = 96 × 363 = 34,848
```

**答案：该层共有 34,848 个需要学习的参数（约 3.5 万，若考虑偏置则再加 96 个，共 34,944）。**

### 1.3 小结

| 项目 | 数值 |
|---|---|
| 输入 | 227 × 227 × 3 |
| 卷积核 | 96 个，11 × 11 × 3，stride = 4，padding = 0 |
| 输出特征图 | **55 × 55 × 96** |
| 参数量（不含偏置） | **34,848** |
| 参数量（含偏置） | 34,944 |

对比：如果第一层的 55×55×96 特征图直接接一个同等规模的**全连接层**，参数量将是 (227×227×3) × (55×55×96) ≈ 4.5 亿——卷积的**局部连接 + 参数共享**把参数量压缩了约 1.3 万倍，这正是 CNN 相对全连接网络的核心优势。

## 2. 思考题（参数共享假设何时不成立）

**题目**：参数共享是 CNN 的核心。请思考在哪些类型的任务或数据上，参数共享这个假设可能不成立，从而使得标准 CNN 表现不佳？（例如，人脸识别中，眼睛的特征和嘴巴的特征是否应该用同一个卷积核来提取？）

### 2.1 参数共享假设回顾

标准 CNN 的平移等变性来自一个隐含假设：**"同一个特征（如边缘、纹理）无论出现在图像的什么位置，都应该用同一组权重来检测。"** 卷积核在整张图上滑动，权重处处相同。

但这个假设本质上要求：**特征具有"位置无关性"**——特征的意义不依赖于它出现在哪里。一旦这个前提不成立，强行共享参数就会损害性能。

### 2.2 参数共享可能失效的场景

**（1）结构有固定语义位置的任务 —— 人脸识别（题目中的例子）**

人脸的五官位置是高度结构化的：眼睛总在上方、嘴巴总在下方、鼻子居中。此时：
- 在眼睛区域，最有用的滤波器是检测"眼球、眼睑、眉骨"等水平带状纹理；
- 在嘴巴区域，最有用的滤波器是检测"嘴唇轮廓、牙齿"等另一种纹理。

如果全脸共享同一组卷积核，网络只能用同一套特征描述眼睛和嘴巴，表达效率很低。**更合理的方式是"局部参数化"**：不同空间区域使用不同的卷积核（如 R-CNN 系列先检测再分类、人脸专用网络中的对齐预处理），让网络"知道自己在看哪里"。这也是为什么人脸识别流程中通常先做**人脸对齐（alignment）**——对齐之后五官位置归一化，参数共享的假设才被部分挽救回来。

**（2）医学影像分析（病灶检测、细胞分类）**

- 器官内部不同位置的组织语义不同：肺部 CT 中，肺尖、肺门、肺底出现的正常结构和病灶形态差异很大；
- 病灶本身尺度小、位置随机但形态特异（如肺结节 vs 血管截面），共享参数的全卷积特征对微小病灶的区分度不足；
- 医学图像常有固定方向约定（如胸片总是头朝上），位置本身携带诊断信息，平移不变性反而是"有害的先验"。

**（3）细粒度分类（Fine-grained Recognition）**

区分"白头翁"和"黄鹂"靠的是眼睛周围 tiny 的局部差异（喙色、眼圈），而不是全图共享的通用纹理。这类任务的关键判别区域小且位置相对固定，标准 CNN 的共享特征容易被大面积背景淹没，往往需要**注意力机制 / 部件检测（part-based）**来打破全局参数共享。

**（4）几何变换不友好的数据 —— 旋转、尺度、视角敏感任务**

参数共享保证的是**平移等变性**，对旋转、缩放、透视变换并不鲁棒：
- 航拍 / 卫星图像中的建筑物、道路可能以任意角度出现，方向是重要语义（如判断河流走向）；
- 工业质检中缺陷的方向性（划痕的方向）本身是判别特征，旋转不变的共享卷积会丢失这一信息。

需要 Group-Equivariant CNN、可变形卷积（Deformable Conv）等方法来放松这一假设。

**（5）非网格 / 不规则数据 —— 图结构数据**

点云、分子结构、社交网络、知识图谱中，数据没有"平铺的网格"概念，每个节点邻居数量、排列都不固定，根本无从"滑动"卷积核。标准 CNN 的参数共享假设在此完全不成立，需要 GNN（图神经网络）按节点自适应地聚合信息。

**（6）多模态 / 通道语义差异大的数据**

标准卷积默认所有输入通道共享同一卷积核的空间模式，当不同通道物理含义截然不同且各自需要独立处理逻辑时（如某些传感器融合数据），跨通道的参数耦合可能不合适。

### 2.3 归纳：什么时候参数共享会失效

| 失效原因 | 典型场景 | 后果 | 常见对策 |
|---|---|---|---|
| 特征的语义与位置强绑定 | 人脸五官、医学影像 | 共享特征表达效率低 | 对齐预处理、部件检测、局部卷积 |
| 关键判别信息在小而固定的区域 | 细粒度分类 | 判别特征被背景淹没 | 注意力机制、part-based 模型 |
| 方向/尺度本身是语义 | 遥感、工业缺陷 | 旋转鲁棒性丢失关键信息 | 等变网络、可变形卷积 |
| 数据无网格结构 | 点云、图数据 | 卷积无法定义 | GNN / PointNet |
| 小目标 + 深层下采样 | 小病灶、小缺陷检测 | 细节在深层丢失 | FPN、高分辨率分支、可变形卷积 |

### 2.4 结论

参数共享是 CNN 高效的原因，但也是它最大的**归纳偏置（inductive bias）**：它把"特征位置无关"这个先验硬编码进了模型。当任务中的特征**位置敏感、方向敏感、结构不规则**时，这个先验就变成了枷锁。回答题目中的例子：**眼睛和嘴巴不应该用同一个卷积核来提取**——在人脸这类具有固定几何结构的任务上，更合理的做法是先对齐/检测局部区域，再在局部使用专门的特征提取器。深度学习的很多进展（注意力、可变形卷积、GNN、视觉 Transformer）本质上都是在**放松或重构参数共享的假设**，让模型根据数据自适应地决定"在哪里共享、共享多少"。
